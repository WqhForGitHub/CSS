水平垂直居中 - 常用方案汇总

居中是 CSS 高频场景。根据元素是否已知宽高、是块级还是文本，方案不同。现代开发中 flex / grid 是首选；老项目兼容时常用 absolute + transform。

方式一：flex 弹性布局（推荐）

display: flex; justify-content: center; align-items: center;
flex 居中

方式二：grid 网格布局（最简洁）

display: grid; place-items: center;
grid 居中

方式三：absolute + transform（未知宽高）

position: absolute; top/left: 50%; transform: translate(-50%, -50%);
transform 居中

方式四：absolute + margin: auto（需已知宽高）

top/right/bottom/left: 0; margin: auto;
margin auto 居中

方式五：absolute + 负 margin（需已知宽高）

top/left: 50%; margin-top/-left 为宽高一半
负 margin 居中

方式六：table-cell + vertical-align

display: table-cell; vertical-align: middle; text-align: center;
table-cell 居中

方式七：line-height（单行文本）

line-height = 容器高度；text-align: center;
单行文本水平垂直居中

方式八：inline-block + 伪元素占位（兼容性好）

父 ::before inline-block 撑高 + vertical-align: middle
inline-block 居中
