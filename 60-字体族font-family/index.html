60. 解读 system-ui 字体栈

完整声明：font-family: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
作用：让网页在各平台使用系统原生 UI 字体，体验一致、加载快、零字体请求。
这是使用了完整 system 字体栈的文字，
在 iOS 上显示 San Francisco，Android 上 Roboto，Windows 上 Segoe UI。

逐项解读

字体名对应系统/字体说明
system-ui 通用 CSS 标准<关键字>，直接使用系统默认 UI 字体（现代浏览器首选）
-apple-system iOS/macOS Apple 私有关键字 → San Francisco（旧称 .SF NS Text）；system-ui 未支持时的兼容
BlinkMacSystemFont macOS Chrome Chrome on macOS 私有关键字，使用 SF
"Segoe UI" Windows Windows Vista 起的默认 UI 字体
Roboto Android Android 默认 UI 字体
Helvetica 旧 macOS/iOS 经典无衬线字体，iOS 9 之前默认
Arial Windows 旧 Windows 上 Helvetica 替代品
sans-serif 通用兜底 通用族兜底，浏览器选一个无衬线字体

设计思路

  • 按平台从新到旧排列：先标准 system-ui，再各平台私有前缀
  • 字体回退链：浏览器逐个尝试，找到第一个可用字体即停止
  • 兜底 sans-serif：确保总有字体可用
  • 原生 UI 字体优势：与系统应用视觉统一、无网络请求、渲染最快

注意事项

  • 带空格的字体名需加引号："Segoe UI"
  • 中文环境通常追加中文优先：..., "PingFang SC", "Microsoft YaHei", sans-serif;
  • 调试时可在 DevTools → Computed 查看 font-family 最终生效值
