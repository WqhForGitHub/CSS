38. 单行/多行文本溢出隐藏

使用 overflow:hidden + text-overflow:ellipsis 实现省略号。

单行溢出

这是非常非常长的一段文字会超出容器宽度需要用省略号截断，超出部分通过 text-overflow:ellipsis 显示为三个点。
.single {
  white-space: nowrap;     /* 不换行 */
  overflow: hidden;
  text-overflow: ellipsis;
}

多行溢出（限定行数）

这是一段用于演示多行省略的文本，会自动在第3行末尾加省略号截断。这是一段较长的文字内容用于展示 webkit 的 line-clamp 特性，需要配合 display -webkit-box 实现弹性盒子布局以及 box-orient vertical 设置纵向排列，再通过 line-clamp 限制行数 итд再多写一些凑行数确保被截断展示省略。
.multi {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;   /* 限制3行 */
  overflow: hidden;
  text-overflow: ellipsis;
}

注：-webkit-line-clamp 现已被主流浏览器支持；旧浏览器可用 JS 测量高度截断。
