外边距折叠 - Margin Collapsing

在常规流中，垂直方向相邻的两个外边距会发生合并（取较大者），称为外边距折叠。触发场景： 相邻兄弟、父子（无 border/padding/BFC 隔离）、空块级元素自身。 注意：只有垂直方向的 margin 会折叠，水平方向不折叠；flex / grid 容器内部也不会折叠。

一、相邻兄弟元素外边距折叠

box margin-bottom: 40px + box-alt margin-top: 30px → 折叠为 40px
Box A：margin-bottom: 40px
Box B：margin-top: 30px（两个间距并未变成 70px，而是取较大值 40px）

二、父子元素外边距折叠

父无 border/padding/BFC → 子的 margin-top 穿透到父外
Child：margin-top: 40px。父元素没有上边框/内边距，子元素的上外边距会"跑到"父元素外面。

四、避免外边距折叠的方式

针对父子折叠，核心思路是让父元素成为独立的 BFC 或在边界处添加 border / padding。

方式一：父元素 overflow: hidden 触发 BFC

parent: overflow: hidden
Child：margin-top: 40px。父元素 BFC 化后，子元素的 margin 被包含在父元素内部。

方式二：父元素加 border-top

parent: border-top: 1px solid
Child：margin-top: 40px。父元素上边框隔断了外边距，margin 不再穿透。

方式三：父元素加 padding-top

parent: padding-top: 1px
Child：margin-top: 40px。父元素内边距同样可以阻止折叠。

方式四：相邻元素改为 inline-block

box-alt: display: inline-block（不再与 box 折叠）
Box A：margin-bottom: 40px
Box B：margin-top: 30px（改为 inline-block 后不参与折叠，间距 = 40 + 30 = 70px）
