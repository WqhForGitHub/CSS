46. 根据设计稿进行移动端适配

常见设计稿宽度 750px（基于 iPhone6/7/8 @2x）。适配核心：让页面在不同屏幕等比缩放。

① viewport meta（基础）

<meta name="viewport"
  content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no">

设置视口宽度等于设备宽度，禁止用户缩放。

② rem 方案（推荐）

原理：JS 根据 deviceWidth 动态设置 html 字号，所有尺寸用 rem。 
// 设计稿 750px 宽，分成 10 份 → 1rem = 75px
document.documentElement.style.fontSize =
  window.innerWidth / 10 + 'px';

// 设计稿中 100px → 写 100/75 ≈ 1.33rem
1.5rem 大字 / 1rem / 0.75rem 小字

缩放浏览器窗口，rem 单位会随根字号变化等比缩放。

③ vw / vh 方案（纯 CSS）

1vw = 视口宽度的 1%，无需 JS。
设计稿 750px 中 100px → 100/750×100 = 13.33vw。
字号 4vw，随窗口变化

④ lib-flexible + postcss-pxtorem（阿里方案）

/* postcss.config.js */
plugins: [
  require('postcss-pxtorem')({
    rootValue: 75,   // 1rem = 75px
    propList: ['*']
  })
]
// 直接按设计稿写 px，工具自动转 rem

⑥ 注意事项

  • 高清图准备 @2x/@3x（参考 demo 34）
  • 1px 边框问题（参考 demo 55）
  • 安全区域 env(safe-area-inset-bottom)
