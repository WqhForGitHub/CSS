flex 布局 - Flexbox Layout

Flexbox（弹性盒布局）是一维布局方案，擅长处理一行或一列中元素的排列与分配。 通过 display: flex 开启，再配合主轴 / 交叉轴属性可灵活控制对齐、 方向、换行与空间分配。是现代 CSS 布局首选方案之一，另一个是 14-grid布局 。
