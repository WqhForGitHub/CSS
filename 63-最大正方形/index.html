63. 浏览器可视区域画最大正方形

最大正方形边长 = min(视口宽, 视口高)。CSS 提供了多种简洁方案。

方案1：100vmin（最简洁推荐）

1vmin = min(1vw, 1vh)，即视口宽高较小者的 1%。

100vmin × 100vmin
.max-square {
  width: 100vmin;
  height: 100vmin;
}

方案2：min() 函数

min(100vw, 100vh)
.max-square {
  width: min(100vw, 100vh);
  height: min(100vw, 100vh);
}

方案3：aspect-ratio + 100vmin

aspect-ratio:1/1 + 100vmin
.max-square {
  width: 100vmin;
  aspect-ratio: 1 / 1;
}

方案4：JS 动态计算

JS 计算
const side = Math.min(window.innerWidth, window.innerHeight);
square.style.width = side + 'px';
square.style.height = side + 'px';
