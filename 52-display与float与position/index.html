52. display / float / position 的关系

三者共同决定元素的布局表现，存在优先级与覆盖规则。

① 优先级（CSS 规范）

1. display: none       → 优先级最高，元素不渲染，float/position 无效
2. position: absolute/fixed → 覆盖 float（float 失效，相当于 none）
3. float: left/right   → 让 display 计算值变为 block（部分）
4. display             → 决定基本盒模型

② position: absolute/fixed 使 float 失效

float:left 元素
同时设 position:absolute + float:left，float 被忽略，按 absolute 定位

③ float 使 inline 元素变成 block（可设宽高）

inline span 浮动后 可设宽高 100×60

span 原本 display:inline 不能设宽高，float 后计算值变 block。

④ absolute/fixed 同样让 display 变 block

span position:absolute

inline span 绝对定位后可设宽高

⑤ display:none 一票否决

display:none + absolute + float → 完全不显示
（上方元素看不见）
组合结果
display:none不渲染，其余全失效
position:absolute/fixed + floatfloat 失效，按定位处理
float + inline 元素display 计算值变 block
float + display:inline-block保持 inline-block 行为
无 float/position按 display 原始值
