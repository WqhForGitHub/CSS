54. 用 CSS 实现扇形

扇形 = 圆的一部分。常用方案：
① border-radius 实现 1/4 圆（90°扇形）
② conic-gradient 锥形渐变实现任意角度
③ clip-path 裁切
④ overflow:hidden + 旋转裁切
90° border-radius
60° conic-gradient
120° conic-gradient
45° conic-gradient
clip-path 三角
clip-path 扇形

关键代码

/* 90° 扇形（1/4 圆） */
.sector-90 {
  width: 100px; height: 100px;
  background: #1890ff;
  border-radius: 100px 0 0 0;  /* 只设一个角的圆角=边长 */
}

/* 任意角度扇形 */
.sector-N {
  width: 100px; height: 100px;
  border-radius: 50%;
  background: conic-gradient(#52c41a 0 60deg, transparent 60deg);
}

conic-gradient 是最灵活的方案，可任意指定起始角和度数；老浏览器兼容可用 SVG 或 canvas 替代。
