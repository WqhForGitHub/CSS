grid 布局 - Grid Layout

CSS Grid 是二维布局方案，可同时控制行与列，适合复杂的整体页面结构。通过 display: grid 开启，再用 grid-template-columns / rows 定义轨道， gap 控制间距，grid-area 命名区域。对比一维的 13-flex布局，grid 更适合整体布局，flex 更适合组件内部排列。
