sticky、fixed、absolute - 定位方案对比

三者都属 CSS 定位，但行为差异显著： sticky 在滚动到达阈值前是普通流，到达后"粘住"（相对滚动容器）； fixed 始终相对视口固定，完全脱离文档流； absolute 相对最近的 position ≠ static 祖先定位，同样脱离文档流。选择时关注"相对谁定位"与"是否需要占位"。
属性 包含块（相对谁定位） 是否脱离文档流 典型场景
sticky 最近的滚动祖先（含视口） 否（占位，阈值前为 relative） 表头吸顶、侧边导航吸顶
fixed 视口（除非祖先有 transform 等） 是 回到顶部按钮、悬浮客服、固定导航
absolute 最近的 position ≠ static 祖先 是 徽标、tooltip、角标、精确叠放

方式一：sticky 粘性定位（吸顶）

position: sticky; top: 0;
在下方滚动区域内上下滚动，观察绿色/橙色/紫色标题在到达顶部时"粘住"的效果。 sticky 必须设置 top/right/bottom/left 之一才会生效。
章节一 标题（sticky 吸顶）
向下滚动，标题会停在容器顶部。 sticky 元素本身仍在文档流中占位，当其父容器滚出视口时，sticky 也会随之离开。 常见坑：若祖先设置了 overflow: hidden ，sticky 会以该祖先为参考而非最近的滚动容器，可能失效。
章节二 标题（sticky 吸顶）
当章节二标题到达顶部时，会顶替章节一标题的位置（章节一已被滚出）。 这是 sticky 与 fixed 的关键区别：sticky 在父容器范围内才"粘"。
章节三 标题（sticky 吸顶）
章节三继续滚动到顶部时吸住，直至整个父容器滚出视口。适合长文档的章节标题、 表格表头、侧边导航等需要"暂时固定"的场景。

方式二：fixed 固定定位

position: fixed; right: 30px; bottom: 30px;
fixed 始终相对视口定位，无论页面如何滚动都固定在同一位置。 页面右下角的两个圆形按钮即为 fixed 定位（回到顶部 / 菜单）。注意： fixed 完全脱离文档流，需预留遮挡空间或保证不影响其他内容。

fixed 的包含块陷阱

若某祖先设置了 transform 、 filter 、 perspective 、 will-change 等属性， fixed 的包含块会变成该祖先而非视口，导致 fixed"失效"。下方演示在受限容器内的固定行为（实际为 sticky 模拟）。
横幅：position: sticky; top: 0
这是一段较高的内容，用于演示在受限容器内的"固定"效果。 当容器设置了 transform 等属性时，内部 fixed 元素会以该容器为包含块， 表现类似"容器内的固定"。

继续滚动，观察横幅是否吸在容器顶部。

方式三：absolute 绝对定位

父 position: relative; 子 position: absolute; top/right/...
absolute 相对最近的 position ≠ static 祖先定位。因此典型用法是父级 position: relative ，子级 position: absolute 精确定位到父级内部某处。
