35. CSS 优化与提高性能的方法

从 加载、选择器、渲染、值 四个层面优化 CSS。

① 加载层面

  • ✗ 避免 @import（同步、阻塞、串行）
  • ✓ 用 link 放 <head>，并行加载
  • ✓ 压缩（minify）去除空白注释
  • ✓ 关键 CSS 内联（首屏），其余按需异步加载
  • ✓ 利用 CDN / HTTP 缓存强缓存
  • ✓ 提取公共样式，避免重复下载

② 选择器层面（匹配从右向左）

/* 避免通配 / 深层嵌套 */
* { box-sizing: border-box; }                  /* ✗ 全匹配 */
#nav .list li a { }                            /* ✗ 过深 */
header ul li .item .txt .link a { }            /* ✗ */

/* 推荐 */
.btn { }              /* 直接类 */
.btn-primary { }      /* 语义化 */
.nav-link { }         /* 扁平 */

③ 渲染层面（减少 reflow/repaint）

  • 尽量用 transform/opacity（合成层）替代 left/top/width
  • 动画元素 position:absolute/fixed 脱离文档流减少影响
  • 用 will-change 提示提前提升为合成层（适量）
  • 批量操作 DOM / class 切换，避免读写交替触发重排
  • visibility:hidden 比 display:none 仅重绘
  • 避免 table-layout（重排成本高）

④ 属性值层面

  • 用 box-sizing:border-box 简化盒模型计算
  • 小数值尽量取整（0.33em 不如 0.3em）
  • 简写合并：margin: 0 auto 替代四个分开
  • 用 CSS 变量 --var 便于主题切换与维护
  • 淘汰 expression、filter 等 IE 性能杀手
