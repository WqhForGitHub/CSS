25. SCSS/Less 与 CSS 的区别

SCSS/Less 是 CSS 预处理器，扩展了 CSS 语法，编译后生成原生 CSS。主要增强： 变量、嵌套、mixin、继承、函数、模块化。

原生 CSS

.btn {
  background: #1890ff;
}
.btn:hover {
  background: #40a9ff;
}
.btn-large {
  background: #1890ff;
  font-size: 18px;
}
.theme .btn {
  color: #fff;
}

SCSS

$primary: #1890ff;        // 变量
@mixin btn {              // mixin
  background: $primary;
}
.btn {
  @include btn;
  &:hover {               // 嵌套 + 父引用
    background: lighten($primary, 10%);
  }
}
.btn-large {
  @extend .btn;           // 继承
  font-size: 18px;
}
.theme .btn { color: #fff; }

主要区别

  • ① 变量：CSS 用 --var + var()；SCSS 用 $，Less 用 @
  • ② 嵌套：预处理器支持选择器嵌套，原生 CSS 不支持
  • ③ Mixin / 继承：复用样式块，减少重复
  • ④ 函数运算：lighten()/darken() 等颜色函数
  • ⑤ 模块化：@import 可拆分文件，CSS 原生 @import 有性能问题
  • ⑥ 需编译：SCSS/Less 必须经编译才能在浏览器运行，CSS 浏览器直接解析
