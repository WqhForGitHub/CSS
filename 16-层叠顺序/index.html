16. 网页元素的层叠顺序（Stacking Order）

层叠顺序（从底到顶）：
1. 负 z-index 的定位元素
2. 普通块级元素（非定位、非浮动）
3. 浮动元素
4. inline / inline-block 元素
5. z-index:auto/0 的定位元素
6. 正 z-index 的定位元素
1. z-index:-1 (最底)
2. 普通块级
3. 浮动
4. inline-block
5. z-index:0
6. z-index:2 (最顶)
  • z-index:-1 定位元素 → 最底层
  • 普通块级元素（position:static）
  • 浮动元素（float）
  • inline / inline-block 元素
  • z-index: 0/auto 的定位元素
  • z-index: > 0 的定位元素 → 最顶层
