57. 默认 display 元素及其他 display 取值

HTML 元素有默认 display 值，由浏览器 UA 样式表规定。

默认 display: block 元素（独占一行）

元素说明
<div>通用块容器
<p>段落
<h1>~<h6>标题
<ul> <ol> <li>列表
<table> <tr> <thead>表格相关
<section> <article> <header> <footer> <nav> <aside> <main>语义化区块
<form> <fieldset>表单容器
<hr> <blockquote> <pre>分隔/引用/预格式
<address> <figure> <figcaption>其他
div
p
h1

↑ 它们各自独占一行

默认 display: inline 元素（不换行）

元素说明
<span>通用行内容器
<a>超链接
<strong> <em> <b> <i>强调/加粗/斜体
<code> <var> <kbd>代码相关
<abbr> <cite> <q>缩写/引用
<sub> <sup> <small>上下标/小字
<label> <output>表单标签
<br> <img> <input>特殊：br/img/input 为行内替换元素
