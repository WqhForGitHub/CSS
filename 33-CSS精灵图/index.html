33. CSS Sprites（雪碧图）

将多个小图标合并为一张大图（雪碧图），通过 background-position 定位显示需要的部分。
优点：减少 HTTP 请求，减少图片字节开销，提升加载速度。
缺点：维护麻烦，修改一个图标需重新拼图；不适合响应式（放大缩小失真）。

关键代码：
.icon { background: url(sprite.png) no-repeat; width:40px; height:40px; }
.icon-1 { background-position: 0 0; }
.icon-2 { background-position: -40px 0; }
position 为负值，把不需要的部分移出显示区域。
现代替代：iconfont 字体图标、SVG sprite、HTTP/2 多路复用后单图请求成本降低，雪碧图使用减少。
