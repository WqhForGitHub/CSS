55. 1px 问题及解决方案

问题：移动端高 DPR 屏（如 DPR=2/3）上，CSS 1px 会对应 2~3 个物理像素，导致边框视觉上偏粗。
本质：设计稿按物理像素绘制 1px，但 CSS 用逻辑像素，需用逻辑 0.5px/0.33px 来对应 1 物理像素。

问题演示

border:1px 在 DPR=2 屏上显示为 2 物理像素（偏粗）

普通 1px 边框

方案1：transform scaleY 伪元素（推荐）

用 1px 伪元素 + transform:scaleY(0.5) 缩放

底部 0.5px 线（伪元素 scaleY）
.scale-1px::after {
  content: '';
  position: absolute; left: 0; bottom: 0;
  width: 100%; height: 1px;
  background: #1890ff;
  transform: scaleY(0.5);
  transform-origin: 0 0;
}

方案2：viewport 缩放（移动端全局）

JS 设置 meta scale=1/dpr，然后按 1px 写、视觉为物理 1px

const dpr = window.devicePixelRatio;
const scale = 1 / dpr;
document.querySelector('meta[name=viewport]').setAttribute(
  'content',
  `width=device-width, initial-scale=${scale}, maximum-scale=${scale}`
);
// 同时把 html 字号放大 dpr 倍以补偿
配合 viewport 缩放的 1px

border-image 渐变模拟

方案4：box-shadow 0.5px

box-shadow: 0 0.5px 0

方案5：直接 0.5px（仅部分浏览器）

border: 0.5px（iOS 支持，部分 Android 失效）

对比

  • transform scaleY：兼容性好，推荐
  • viewport 缩放：全局解决，但影响所有尺寸（需配合 rem 补偿）
  • 0.5px 直接写：最简单但兼容性差
  • border-image：圆角难处理
