58. line-height: 100% 与 line-height: 1 的区别

两者在当前元素上效果相同（行高 = 自身 font-size），但继承给子元素时差异显著。
百分比 / 长度：继承的是计算后的绝对值。
纯数字（无单位）：继承的是比例因子，子元素根据自身字号重算。

基础对比（父 20px）

父 line-height:100% → 20px
子 font-size:30px → 继承到的行高仍是 20px（绝对值，文字溢出）
父 line-height:1 → 20px
子 font-size:30px → 行高 = 30×1 = 30px（按比例重算，正常）

更多赋值对比

line-height:1.5 → 30px（无单位比例，子30px→45px）
子 30px → 行高 45px
line-height:24px（绝对长度，子也是 24px）
子 30px → 行高仍是 24px

可视化行高区域（背景显示行盒）

line-height:100%（行盒=20px，紧贴文字）
line-height:1（行盒=20px）
line-height:1.5（行盒=30px，文字上下留白）

赋值方式总结

写法当前元素继承给子元素
line-height: 100%= font-size继承计算后的绝对值
line-height: 1（无单位）= font-size继承比例因子，子按自身字号重算
line-height: 1.5em= 1.5×font-size继承绝对值
line-height: 24px固定值继承固定值
line-height: normal浏览器默认≈1.2继承 normal（子按自身算）

结论：全局设置推荐 line-height: 1.5 等无单位数字，子元素按自身字号自适应。
