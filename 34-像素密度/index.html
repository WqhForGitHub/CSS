34. 物理像素 / 逻辑像素 / 像素密度

物理像素（设备像素）：屏幕实际发光点个数，硬件固定。
逻辑像素（CSS 像素）：CSS 中使用的 px，是抽象单位；浏览器按 DPR 映射到物理像素。
设备像素比 DPR = 物理像素 / 逻辑像素（iPhone 常见 DPR=2 或 3）。
像素密度 PPI = 每英寸的物理像素数。
关系：
物理像素 = 逻辑像素(CSS px) × 设备像素比(DPR)
例：iPhone DPR=2，CSS 1px 实际占 2×2=4 个物理像素。
为什么需要 @2x @3x 图？
高 DPR 屏上一个 CSS 像素对应多个物理像素，若仍用 @1x 图则被拉伸变模糊。
提供 @2x/@3x 高清图，让每个物理像素都有真实色彩信息，所以图片更清晰。 通过 media query 或 srcset 选择匹配 DPR 的图： 
@media (-webkit-min-device-pixel-ratio: 2), (min-resolution: 2dppx) {
  .logo { background-image: url(logo@2x.png); }
}
