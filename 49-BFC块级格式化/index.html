49. BFC（块级格式化上下文）

BFC（Block Formatting Context）：块级格式化上下文，是一个独立的渲染区域，内部元素的布局不影响外部，外部也不影响内部。
核心特性：① 内部 Box 垂直排列；② 计算 BFC 高度时包含浮动子；③ BFC 区域不会与浮动 box 重叠；④ 内外 margin 不重叠。

如何创建 BFC

方式说明
float ≠ none浮动元素
position: absolute / fixed绝对/固定定位
display: inline-block / flex / grid / table-cell / flow-root特定 display 值
overflow ≠ visible（hidden/auto/scroll）最常用
contain: layout/content/paint现代方案

推荐用 display: flow-root（专为创建 BFC 设计，无副作用）。
