清除浮动 - Clear Float

子元素设置 float 后会脱离文档流，导致父元素高度塌陷（无法被浮动的子元素撑开）。 后续正常流元素会顶上来与浮动元素重叠。清除浮动的本质是让父元素重新包含浮动子元素。

问题：父元素高度塌陷

父元素未清除浮动 → 高度为 0，下方文字顶上来
1
2
3
这段文字本应在浮动元素下方，但因为父元素塌陷，它与浮动元素重叠了。

方式一：额外标签 clear: both

在浮动元素后加一个空 div: clear: both
1
2
3
下方文字正常显示在浮动元素之下。缺点：添加了无语义的额外标签。

方式二：父元素 overflow: hidden 触发 BFC

parent: overflow: hidden（或 auto）
1
2
3
下方文字正常显示。缺点：子元素超出父元素时会被裁切；配合定位会有副作用。

方式三：单伪元素 :after（推荐）

父元素 ::after { content:""; display:block; clear:both; }
1
2
3
下方文字正常显示。不增加额外标签，是最常用的方案。

方式四：双伪元素 clearfix（经典通用）

::before/::after + display: table + clear: both
1
2
3
下方文字正常显示。::before 用 display:table 可同时防止父子 margin 折叠，是 Bootstrap 等框架采用的方案。

方式五：display: flow-root（现代方案）

parent: display: flow-root
1
2
3
下方文字正常显示。专为清除浮动设计，无副作用，现代浏览器首选（IE 不支持）。
