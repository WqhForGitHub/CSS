用纯 CSS 绘制三角形

经典方案利用 border 的特性：当元素 width/height 为 0 时，相邻两条 border 的交界处会形成 45° 斜边。 现代方案可用 clip-path 或 transform: rotate 实现。

原理：四条 border 在 width/height 为 0 时拼接成四个三角形

width:0; height:0; border 四方向各一色
四色拼接，可见斜边
