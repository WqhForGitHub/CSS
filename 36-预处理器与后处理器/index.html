36. CSS 预处理器 / 后处理器

预处理器：用增强语法（变量/嵌套/mixin）写 CSS，编译成原生 CSS。
后处理器：处理已经写好的标准 CSS，加前缀、压缩、降级等改造。
典型流程：源码 → 预处理器 → 标准 CSS → PostCSS → 生产 CSS。

预处理器（如 SCSS / Less）

$primary: #1890ff;
@mixin center {
  display: flex;
  align-items: center;
  justify-content: center;
}
.btn {
  @include center;
  color: $primary;
  &:hover { color: darken($primary, 10%); }
}

提供变量、嵌套、mixin、继承、函数等抽象能力，提升可维护性。

后处理器（如 PostCSS）

/* 源 CSS */
.box {
  display: flex;
  user-select: none;
}

/* PostCSS 处理后 */
.box {
  display: -webkit-box;
  display: -webkit-flex;
  display: -ms-flexbox;
  display: flex;
  -webkit-user-select: none;
     -moz-user-select: none;
      -ms-user-select: none;
          user-select: none;
}

自动加前缀（autoprefixer）、CSS 变量降级、压缩、未来语法 polyfill。

为什么要使用？

  • 变量 / 模块化 → 消除重复，便于主题
  • 嵌套 → 层级清晰，作用域明确
  • 自动前缀 → 不用手写 -webkit- 等厂商前缀
  • 未来语法 postcss-preset-env → 提前用 CSS Next
  • 搭配工程化 → 统一封装、压缩、按需加载
