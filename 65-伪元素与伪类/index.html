65. CSS 伪元素与伪类的作用和区别

伪类（pseudo-class）：单冒号 :，选中处于某种状态的真实元素，不创建新元素。
伪元素（pseudo-element）：双冒号 ::，创建文档树中不存在的虚拟元素。
CSS3 规范用单/双冒号区分，但单冒号写伪元素（如 :before）仍向后兼容。

对比表

对比项伪类伪元素
冒号单冒号 :双冒号 ::
本质状态选择器创建虚拟元素
DOM选中已有元素创建不存在元素
数量可叠加多个每元素仅一个（::before+::after 共两个）
是否需 content否是（::before/::after 必须有 content）
典型:hover/:focus/:nth-child/:not/:checked/:first-child::before/::after/::first-letter/::first-line/::selection/::placeholder

常见伪类清单

  • 交互：:hover :active :focus :focus-within :visited
  • 结构：:first-child :last-child :nth-child(n) :only-child :nth-of-type
  • 表单：:checked :disabled :enabled :valid :required
  • 否定：:not()
  • CSS4：:has() :is() :where()

常见伪元素清单

  • ::before / ::after：在元素内容前后插入
  • ::first-letter：首字母
  • ::first-line：首行
  • ::selection：被选中文字
  • ::placeholder：输入框占位符
  • ::marker：列表项标记

双冒号与单冒号的兼容

CSS2 时伪元素也用单冒号（:before），CSS3 为区分改为双冒号（::before）。

现代浏览器对 :before 仍兼容，但推荐用双冒号写伪元素以符合规范。
