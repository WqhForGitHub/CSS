# 1. 坐标系

旅程开始之前，先花点时间调整一下。变形涉及两种坐标系，最好事先了解一下。

>如果你已经熟知笛卡尔坐标系和球坐标系，尤其是在运算中的用法，可以跳到下一小节。

首先是笛卡尔坐标系，也就是通常所说的 x/y/z 坐标系。这种坐标系使用两个数字（二维）或三个数字（三维）表示一个点在空间中的位置。在 CSS 中，这个坐标系使用三个轴表示：x 轴（横轴）、y 轴（纵轴）和 z 轴（深度轴），如下图所示。

![](https://front-end-1257950569.cos.ap-guangzhou.myqcloud.com/CSS%20%E6%9D%83%E5%A8%81%E6%8C%87%E5%8D%97%EF%BC%88%E7%AC%AC4%E7%89%88%EF%BC%89/%E7%AC%AC16%E7%AB%A0%EF%BC%9A%E5%8F%98%E5%BD%A2/CSS%20%E5%8F%98%E5%BD%A2%E5%8A%9F%E8%83%BD%E4%B8%AD%E8%A1%A8%E7%A4%BA%E7%AC%9B%E5%8D%A1%E5%B0%94%E5%9D%90%E6%A0%87%E7%B3%BB%E7%9A%84%E4%B8%89%E4%B8%AA%E8%BD%B4.png)

2D（二维）变形只需关注 x 轴和 y 轴。按约定，x 轴上的正值在右侧，负值在左侧。类似地，y 轴上的正值沿纵轴向下，负值沿纵轴向上。

这有点奇怪，学过初等代数的人大都知道，数值越大位置应该越高，而不是越低（在上图中，y 标注在 y 轴的底部。三个轴的标注都在正方向那一侧）。如果你用过 CSS 中的绝对定位，回想一下绝对定位元素时使用的 top 属性：值为正数时元素下移，值为负数时则上移。

鉴于此，若想把元素向左下方移动，要把 x 值设为负数、把 y 值设为正数，如下所示：

```css
translateX(-5em)translateY(33px);
```

稍后就会发现，这个变形值是有效的。上述代码的作用是把元素向左移动 5em、向下移动 33 像素。

<br>

如果想在三维空间中改变元素的形态，要加上 z 轴值。这个轴从显示器上跃出，指向你的眼前。理论上，就是这样。z 轴上的正值离你较近，负值离你较远。在这方面，z 轴与 z-index 属性是完全一样的。

下面在上述移动过的元素上再加个 z 轴值：

```css
translateX(-5em) translateY(33px) translateZ(200px);
```

现在，与未指定 z 值相比，元素离我们的距离近了 200 像素。

你可能觉得奇怪，元素怎么可能离我们近了 200 像素，毕竟全息显示器非常少见，而且价格不菲。我与显示器之间的 200 像素有多少摩尔的空气。元素离自己近了到底有什么效果，如果近在眼前。这些问题在后文将逐一解答。现在，你只要相信，在 z 轴上移动元素看起来就是把元素移近或移远即可。

真正需要注意的是，每个元素都有自己的参照系，各轴都相对自身而动。也就是说，如果旋转了元素，轴也随之旋转，如下图所示。旋转之后再变形，是相对旋转后的轴计算的，而不是显示器的轴。

![](https://front-end-1257950569.cos.ap-guangzhou.myqcloud.com/CSS%20%E6%9D%83%E5%A8%81%E6%8C%87%E5%8D%97%EF%BC%88%E7%AC%AC4%E7%89%88%EF%BC%89/%E7%AC%AC16%E7%AB%A0%EF%BC%9A%E5%8F%98%E5%BD%A2/%E5%9F%BA%E6%9C%AC%E5%8F%82%E7%85%A7%E7%B3%BB.png)

<br>

提到旋转，这就引出 CSS 变形功能使用的另一个坐标系，球坐标系。这个坐标系用于描述 3D 空间中的角度，如下图所示。

![](https://front-end-1257950569.cos.ap-guangzhou.myqcloud.com/CSS%20%E6%9D%83%E5%A8%81%E6%8C%87%E5%8D%97%EF%BC%88%E7%AC%AC4%E7%89%88%EF%BC%89/%E7%AC%AC16%E7%AB%A0%EF%BC%9A%E5%8F%98%E5%BD%A2/CSS%20%E5%8F%98%E5%BD%A2%E5%8A%9F%E8%83%BD%E4%BD%BF%E7%94%A8%E7%9A%84%E7%90%83%E5%9D%90%E6%A0%87%E7%B3%BB.png)

<br>

在 2D 变形中只需关注全周 360 度极坐标系，即由 x 轴和 y 轴构成的平面。对旋转来说，2D 旋转其实是在绕 z 轴旋转。类似地，如果绕 x 轴旋转，元素将偏向我们或远离我们，而绕 y 轴旋转的话，元素将向两侧翻转。这些旋转方式如下图所示。

![](https://front-end-1257950569.cos.ap-guangzhou.myqcloud.com/CSS%20%E6%9D%83%E5%A8%81%E6%8C%87%E5%8D%97%EF%BC%88%E7%AC%AC4%E7%89%88%EF%BC%89/%E7%AC%AC16%E7%AB%A0%EF%BC%9A%E5%8F%98%E5%BD%A2/%E7%BB%95%E4%B8%89%E4%B8%AA%E8%BD%B4%E6%97%8B%E8%BD%AC.png)

<br>

再回到 2D 旋转。假设我们想在显示器平面上（即绕 z 轴）顺时针旋转一个元素 45 度。那么使用的变形值可能是下面这样的：

```css
rotate(45deg);
```

如果把值改为 -45deg，元素将绕 z 轴逆时针旋转。换句话说，元素在 xy 平面上旋转，如下图所示。

![](https://front-end-1257950569.cos.ap-guangzhou.myqcloud.com/CSS%20%E6%9D%83%E5%A8%81%E6%8C%87%E5%8D%97%EF%BC%88%E7%AC%AC4%E7%89%88%EF%BC%89/%E7%AC%AC16%E7%AB%A0%EF%BC%9A%E5%8F%98%E5%BD%A2/%E5%9C%A8%20xy%20%E5%B9%B3%E9%9D%A2%E4%B8%8A%E6%97%8B%E8%BD%AC.png)

好的，了解这些基础知识之后，我们开始变形。

# 2. 变形

变形其实只有一个属性，不过有几个辅助属性用于控制如何变形。先从主要的属性入手。

```css
transform

取值：<transform-list> | none
初始值：none
适用于：除基元行内框之外的所有元素（见下文的说明）
百分数：相对范围框计算（见下文的说明）
计算值：指定的值，不过相对长度值会计算为绝对长度
继承性：否
动画性：作为一种变形
```

先说明什么是范围框。受 CSS 控制的元素，其范围框是边框框，即元素边框的外边界。也就是说，计算范围框时，轮廓和外边距不算在内。

>以表格形式显示的元素，其范围框是表格的容器框，包括表格框和相应的表题框。

<br>

如果使用 CSS 改变可缩放矢量图形（SVG）的形态，其范围框是 SVG 图形定义的对象范围框。

注意，变形的元素有自己的堆叠上下文。经过缩放的元素可能比变形前小或大，不过元素的页面上所占的空间与变形前保持不变。这一点对所有变形函数都成立。

取值句法中的 `<transform-list>` 也需要说明一下。这个占位符表示一个或多个变形函数，一个接一个，中间以空格分隔，像下面这样，结果如下图所示：

```css
#example {
    transform: rotate(30deg) skewX(-25deg) scaleY(2);
}
```

![](https://front-end-1257950569.cos.ap-guangzhou.myqcloud.com/CSS%20%E6%9D%83%E5%A8%81%E6%8C%87%E5%8D%97%EF%BC%88%E7%AC%AC4%E7%89%88%EF%BC%89/%E7%AC%AC16%E7%AB%A0%EF%BC%9A%E5%8F%98%E5%BD%A2/%E5%8F%98%E5%BD%A2%E5%90%8E%E7%9A%84%20div%20%E5%85%83%E7%B4%A0.png)

<br>

变形函数一次只处理一个，从第一个（最左边）开始，一直到最后一个（最右边）。从头到尾的处理顺序是很重要的，顺序变了，得到的结果可能就大有不同。请看下面两个规则，结果如下图所示：

```css
img#one {
    transform: translateX(200px) rotate(45deg);
}

img#two {
    transform: rotate(45deg) translateX(200px);
}
```

![](https://front-end-1257950569.cos.ap-guangzhou.myqcloud.com/CSS%20%E6%9D%83%E5%A8%81%E6%8C%87%E5%8D%97%EF%BC%88%E7%AC%AC4%E7%89%88%EF%BC%89/%E7%AC%AC16%E7%AB%A0%EF%BC%9A%E5%8F%98%E5%BD%A2/%E4%B8%8D%E5%90%8C%E7%9A%84%E5%8F%98%E5%BD%A2%E9%A1%BA%E5%BA%8F%EF%BC%8C%E4%B8%8D%E5%90%8C%E7%9A%84%E7%BB%93%E6%9E%9C.png)

在第一个示例中，图像先沿 x 轴移动 200 像素，然后旋转 45°。在第二个示例中，图像先旋转 45°，然后沿 x 轴移动 200 像素，然而这里的 x 轴指的是变形后的元素的 x 轴，而不是父元素、页面或视区的 x 轴。也就是说，元素旋转后，其 x 轴（及其他轴）也随之旋转了。所有变形都是相对元素自己的参照系实施的。

<br>

相比之下，不管先移动再缩放，还是先缩放再移动，得到的结果都是一样的：

```css
img#one {
    transform: translateX(100px) scale(1.2);
}

img#two {
    transform: scale(1.2) translateX(100px);
}
```

顺序有影响的情况要比没有影响的情况多得多，因此一般来说，最好假定始终需要考虑顺序，即便严格来说并非总是如此。

注意，有多个变形函数时，每个都要正确设置，确保全部有效。即使有一个函数是无效的，整个值都将失效。例如：

```css
img#one {
    transform: translateX(100px) scale(1.2) rotate(22);
}
```

因为 rotate() 的值是无效的（旋转至必须带单位），所以整个值都将被忽略。目标图像就待在原来的位置上，没有平移也没有缩放，更别说旋转了。

<br>

此外还要注意，变形通常不叠加。也就是说，如果改变了元素的形态，而后想再添加一种变形，那么要在原变形的基础上修改。请看下面两种情况，结果如下图所示：

```css
#ex01 {
    transform: rotate(30deg) skewX(-25deg);
}

#ex01 {
    transform: scaleY(2);
}

#ex02 {
    transform: rotate(30deg) skewX(-25deg);
}

#ex02 {
    transform: rotate(30deg) skewX(-25deg) scaleY(2);
}
```

![](https://front-end-1257950569.cos.ap-guangzhou.myqcloud.com/CSS%20%E6%9D%83%E5%A8%81%E6%8C%87%E5%8D%97%EF%BC%88%E7%AC%AC4%E7%89%88%EF%BC%89/%E7%AC%AC16%E7%AB%A0%EF%BC%9A%E5%8F%98%E5%BD%A2/%E8%A6%86%E7%9B%96%E6%88%96%E4%BF%AE%E6%94%B9%E5%8F%98%E5%BD%A2.png)

在第一种情况下，第二个规则完全取代了第一个规则，因此元素只会在 y 轴上缩放。这其实不难理解，就像你在一个地方为元素声明了字号，又在另一个地方为元素声明不同的字号一样，字号是不叠加的，只有其中一个字号起作用。在第二个示例中，第一个规则中的变形都出现在第二个规则中，因此它们将与 scaleY() 函数一起起作用。

<br>

不过动画变形例外，不管使用过渡还是真正的动画，效果是叠加的。因此，可以直接在变形的元素上以动画的形式呈现其中一个变形函数，其他变形函数不会被覆盖。假如现在是这样的：

```css
img#one {
    transform: translateX(100px) scale(1.2);
}
```

如果又以动画的形式呈现旋转角度的过程，元素将从平移并缩放后的状态开始旋转到新角度，平移和缩放都将实施。

有趣的是，即使不显式使用过渡或动画，也能通过用户交互伪类（例如 :hover）实现叠加的变形。这是因为悬停等效果就是一种过渡，只不过不是由过渡属性触发的。因此，可以像下面这样声明：

```css
img#one {
    transform: translateX(100px) scale(1.2);
}

img#one:hover {
    transform: rotate(-45deg);
}
```

鼠标悬停在这个图像上，图像在平移并缩放后将向左旋转 45°。旋转过程持续零秒，因为没有声明过渡持续时间，但这仍是一种过渡，只不过是隐式的。因此，状态变化都可以视作过渡，而且状态变化带来的影响都会叠加在之前的变形上。

特别注意，截至写作本书时，变形不能应用到基元行内框上。基元行内框指 span、超链接等行内框。这些元素可以随块级父元素一起变形，但是不能直接旋转 span 元素，除非把显示方式改为 display: block、display: inline-block 等。这一限制的根源在于不确定性。假设一个 span 元素（或其他行内框）分为多行，如何旋转？每个行框独自旋转，还是全部行框作为一个整体旋转？现在还没有统一的答案，争论仍在继续，因此目前无法直接改变行内框的形态。

<br>

## 变形函数

写作本书时，一共有 21 个变形函数。不同的变形函数利用不同格式的值实施相应的变形。这些可用的变形函数及其值的格式见表16-1。

translate()          scale()          rotate()          skew()          matrix()

translate3d()     scale3d()     rotate3d()      skewX()        matrix3d()

translateX()       scaleX()       rotateX()         skewY()        perspective()

translateY()       scaleY()       rotateY()

translateZ()       scaleZ()      rotateZ()      

transform 属性的值通常是由空格分隔的一个或多个函数，各函数从头（左）至尾（右）依次处理，而且每个函数的值都必须是有效的。倘若有一个函数的值是无效的，那么 transform 属性的整个值都将失效，因而也就不做任何变形。

<br>

## 平移函数

平移变形指沿一个轴或多个轴移动，例如，translateX() 沿元素自身的 x 轴移动元素，translateY() 沿元素自身的 y 轴移动元素，translateZ() 沿元素自身的 z 轴移动元素。

| 函数                       | 可取的值                  |
| -------------------------- | ------------------------- |
| translateX(), translateY() | `<length> | <percentage>` |

这两个通常称为 2D 平移函数，因为它们能上下移动元素，也能左右移动元素，但是不能沿 z 轴前后移动元素。这两个函数的值都是一个距离值，可以是长度，也可以是百分数。

值为长度时，效果与你预想的差不多。使用 translateX(200px) 沿 x 轴移动 200 像素的结果是元素向右移动 200 像素。换成 translateX(-200px)，元素则向左移动 200 像素。对 translateY() 来说，正值向下移动元素，负值向上移动元素，而是都是相对元素自身的轴而言的。因此，如果通过旋转对调上下两边，那么 translateY() 的正值将在页面上向上移动元素。
