53. absolute 与 fixed 的共同点和区别

两者都是定位元素，行为相似但参考对象不同。

共同点

  • 都脱离文档流，不占原空间
  • 都可用 top/right/bottom/left 定位
  • 都可用 z-index 控制层叠
  • 都使 inline 元素 display 计算值变 block（可设宽高）
  • 默认宽度由内容决定（不再撑满父容器）
  • 都会让 float 失效

区别1：定位参考不同

absolute：相对最近的非 static 定位祖先，无则相对初始包含块（body）。

fixed：相对浏览器视口（一般情况）。

滚动此区域：

占位内容...
absolute bottom:10 right:10（随滚动移动）

↑ absolute 元素在容器滚动时随之移动

fixed bottom:20 right:20（视口固定，不随滚动）

↑ fixed 元素固定在视口右下，滚动整页也不动

区别2：fixed 的"例外"——祖先含 transform/filter 创建新包含块

若祖先元素设置了 transform/filter/perspective/will-change 等，fixed 会改为相对该祖先而非视口。

占位...
fixed（但相对紫色容器，非视口）
对比absolutefixed
定位参考最近定位祖先视口（默认）
滚动表现随页面/祖先滚动固定不动
包含块可变由 position 祖先决定transform/filter 等可改变
典型场景提示框、菜单、徽标导航栏、回到顶部、悬浮按钮
