39. Sass / Less 是什么？为什么要使用？

Sass 和 Less 都是 CSS 预处理器，扩展 CSS 语法的脚本语言，最终编译为原生 CSS。

Sass（.scss / .sass）

// 变量用 $
$primary: #1890ff;

// mixin
@mixin center {
  display: flex;
  align-items: center;
  justify-content: center;
}

// 嵌套 + 父引用
.btn {
  @include center;
  color: $primary;
  &:hover { color: darken($primary, 10%); }
}

// 继承
.btn-primary { @extend .btn; background: $primary; }

Less（.less）

// 变量用 @
@primary: #1890ff;

// mixin（直接类名复用）
.center() {
  display: flex;
  align-items: center;
  justify-content: center;
}

.btn {
  .center();
  color: @primary;
  &:hover { color: darken(@primary, 10%); }
}

.btn-primary {
  &:extend(.btn);
  background: @primary;
}

Sass vs Less

对比SassLess
变量符号$var@var
语法SCSS（类似CSS）/ 缩进式 .sass类似 CSS
环境Ruby/Node（dart-sass）JavaScript（Node/浏览器）
函数更丰富的内置函数相对少
循环/条件支持 @if/@for/@each支持（守卫 when）
热度更主流较老

为什么要用？

  • 变量化主题色，一处改全局生效
  • 嵌套使结构更清晰，作用域明确
  • mixin / 继承复用样式，消除重复
  • 函数运算：颜色明暗、单位换算
  • 模块化拆分文件，提升可维护性
