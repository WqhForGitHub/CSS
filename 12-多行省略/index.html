多行文字省略 - Multi-line Ellipsis

多行省略指限定显示若干行，超出部分用省略号表示。现代方案使用 -webkit-line-clamp（虽带 -webkit- 前缀，但已被各大浏览器广泛支持）； 兼容老浏览器可用 line-height + height + 伪元素遮罩 方案。单行省略见 11-文字溢出省略。

方式一：-webkit-line-clamp（推荐）

display: -webkit-box + -webkit-box-orient: vertical + -webkit-line-clamp: n + overflow: hidden

方式二：兼容方案（line-height + height + 伪元素）

固定行高与高度 → overflow: hidden → ::after 渐变 + "..."
多行文字省略示例：CSS 是前端开发中非常重要的技能之一，掌握它可以让你的页面布局更加灵活、美观，并且能够实现各种复杂的交互效果。本示例展示如何用纯 CSS 实现多行文本的省略号效果。这种方式兼容性好，但当文字恰好填满最后一行时，省略号会多出来，需配合 JS 判断。

方式三：line-clamp + max-height 兜底

-webkit-line-clamp + max-height: 行高 × 行数
多行文字省略示例：CSS 是前端开发中非常重要的技能之一，掌握它可以让你的页面布局更加灵活、美观，并且能够实现各种复杂的交互效果。本示例展示如何用纯 CSS 实现多行文本的省略号效果。max-height 作为兜底，防止某些环境下 line-clamp 失效导致溢出过多。
