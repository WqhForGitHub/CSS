45. 元素水平垂直居中

居中方案众多，分定宽高与不定宽高两类。

① Flex（最常用，不定宽高）

display:flex; justify-content:center; align-items:center

Flex 居中

② Grid（最简洁，不定宽高）

display:grid; place-items:center

Grid 居中

③ 绝对定位 + transform（不定宽高）

top/left:50% + translate(-50%,-50%)

transform 居中

④ 绝对定位 + margin:auto（需定宽高）

top/right/bottom/left:0 + margin:auto

80×40

⑤ 绝对定位 + 负 margin（需定宽高）

top/left:50% + margin 负宽高一半

80×40

⑥ table-cell（兼容老浏览器）

display:table-cell + vertical-align:middle + text-align:center

table 居中

⑦ line-height（仅单行文本）

line-height = 容器高度

单行文本居中
