  • CSS Grid 是一个二维布局系统，可以同时控制行和列。它非常适合复杂的页面布局。
  • Flexbox 是一维布局模型，适合在单一方向上排列元素。它与 Grid 互补使用。
  • CSS 自定义属性（变量）允许定义可复用的值，使用 var() 引用。
  • 使用媒体查询、弹性单位、auto-fit/minmax 等技术实现自适应布局。
