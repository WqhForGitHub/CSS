第一章：CSS基础

CSS（层叠样式表）是用于描述HTML文档呈现方式的语言。它控制颜色、布局、字体等视觉方面。

第二章：选择器

CSS选择器用于选取要设置样式的HTML元素。包括标签选择器、类选择器、ID选择器、属性选择器等。

第三章：盒模型

CSS盒模型描述了元素的内容区域、内边距、边框和外边距。理解盒模型是掌握CSS布局的基础。

第四章：布局

CSS提供了多种布局方式：正常流、浮动、定位、Flexbox和Grid。现代布局推荐Flexbox和Grid。

Grid 定义整体两列布局，各列独立滚动。内容区中的 h4 使用 position: sticky; top: 0 实现章节标题吸顶。Grid + sticky 是文档类网站的最佳布局方案。
