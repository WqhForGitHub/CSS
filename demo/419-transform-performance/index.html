transform 性能优化

transform 和 opacity 是仅有的两个不会触发重排（reflow）的动画属性，它们在合成层（compositor）上运行，性能最佳。

transform 性能对比

左为 transform 动画（绿色，推荐），右为 left 动画（红色，不推荐）：

transform ✓
left ✗

性能对比表

transform 触发合成层，不重排不重绘，GPU 加速
left/top 触发重排（reflow）+ 重绘（repaint），性能差
opacity 触发合成层，不重排不重绘，GPU 加速
margin 触发重排，影响相邻元素
will-change 提前告知浏览器优化，配合 transform 使用
做动画时优先使用 transform 和 opacity，避免使用 left/top/margin/width/height 等触发重排的属性。
