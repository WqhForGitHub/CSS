字体回退切换效果演示

演示字体加载过程中回退字体的切换效果。通过 font-display: swap 实现平滑切换。
@font-face { font-family: "Custom Font"; src: url("custom.woff2") format("woff2"); font-display: swap; /* 关键属性 */ } .text { font-family: "Custom Font", Arial, sans-serif; }
这段文字先以 Arial 显示，字体加载后切换为 Custom Font。
切换过程：
1. 页面加载 → 立即用 Arial 显示文本（FOUT）
2. 字体下载完成 → 平滑替换为 Custom Font
3. 用户始终能看到文本内容
font-display: swap 是性能与体验的最佳平衡点。
