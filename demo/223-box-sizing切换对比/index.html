box-sizing 切换对比

并排展示 content-box 与 border-box 在相同 width 下的实际表现差异。
content-box
width + padding + border
设置 width:100%，但 padding 和 border 额外增加宽度，可能溢出容器
border-box
width 包含一切
设置 width:100%，padding 和 border 在 width 内，绝不溢出容器
并排对比（flex:1）：
content-box
border-box
↑ content-box 因 padding+border 撑大而换行；border-box 始终保持等宽并排
实际项目中推荐全局应用 *,*::before,*::after { box-sizing: border-box; } 避免布局意外。
