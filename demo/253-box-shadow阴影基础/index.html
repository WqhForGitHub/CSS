box-shadow阴影基础

box-shadow: offset-x offset-y blur spread color 为元素添加阴影效果，可设置内阴影 inset。
box-shadow 各种效果
硬阴影
5px 5px 0
模糊阴影
5px 5px 10px
发光效果
0 0 15px
底部阴影
0 5px 15px
内阴影
inset 0 0 20px
扩展阴影
5px 5px 10px 5px
左上阴影
-5px -5px 15px
模拟边框
0 0 0 3px
参数顺序：水平偏移、垂直偏移、模糊半径、扩展半径、颜色。inset 将外阴影改为内阴影。0 0 0 Npx 可模拟边框且不影响布局。
