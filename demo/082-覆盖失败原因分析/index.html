覆盖失败原因分析

分析常见的 CSS 覆盖失败原因：权重不足、继承干扰、顺序错误、属性不支持等。
原因 1：权重不足 — .text 无法覆盖 #main .text。解决：提高权重或减少目标选择器权重。
原因 2：继承值无权重 — 父元素 color:red 是继承值，子元素任何 color 都能覆盖。
原因 3：引入顺序 — CSS 文件引入顺序错误，后引入的覆盖了先引入的。解决：调整 link 顺序。
原因 4：!important 滥用 — 之前的 !important 无法被正常覆盖。解决：移除不必要的 !important。
遇到覆盖失败时，先用 DevTools 查看被覆盖的声明（删除线标记）。
