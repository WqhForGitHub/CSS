什么是 CSS 动画？▶
CSS 动画通过 @keyframes 定义关键帧，使用 animation 属性应用动画，可以实现复杂的自动播放动画效果。
transition 和 animation 的区别▶
transition 需要触发条件（如 hover），且只有起止两个状态；animation 可以定义多个关键帧，可以自动循环播放。
animation 的性能优势▶
animation 操作 transform 和 opacity 时不会触发重排，运行在合成层上，性能优异，适合做复杂动画。
如何控制动画播放▶
使用 animation-play-state: paused/running 可以暂停和恢复动画。结合 hover 可以实现悬停暂停效果。
虽然这里主要用 transition 实现，但也可以用 animation 实现更复杂的展开动画，如弹性效果。
