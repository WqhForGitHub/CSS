第4章：值和单位

1. 绝对长度单位（1in = 2.54cm = 25.4mm = 72pt = 6pc = 96px）

margin-left: 1in
margin-left: 2.54cm
margin-left: 25.4mm
margin-left: 72pt
margin-left: 6pc
margin-left: 96px

以上六个外边距在理论上完全相同（均为1英寸）。

2. em 与 rem 单位

em 相对当前元素字号

h1: 24px, margin-left: 1em (= 24px)

h2: 18px, margin-left: 1em (= 18px)

p: 12px, margin-left: 1em (= 12px)

em vs rem 对比

父元素 font-size: 16px

font-size: 2em = 32px（相对父元素）
font-size: 2rem = 32px（相对根元素 html）

3. 视区单位（vw / vh）

width: 50vw（视口宽度的50%）
height: 15vh（视口高度的15%）

4. ch 单位

width: 40ch（约40个等宽字符的宽度）

5. calc() 计算函数

width: calc(100% - 40px)，减去两侧各20px的效果

6. 颜色值类型

color: red（命名颜色）

color: #f00（3位十六进制）

color: #ff0000（6位十六进制）

color: rgb(255, 0, 0)（RGB数值）

color: rgb(100%, 0%, 0%)（RGB百分比）

color: rgba(255, 0, 0, 0.5)（RGBA半透明红）

color: hsl(0, 100%, 50%)（HSL红色）

color: hsla(0, 100%, 50%, 0.5)（HSLA半透明红）

7. 全局关键字：inherit / initial / unset

父元素 color: blue，span 使用 color: inherit 继承蓝色
父元素 color: red，em 使用 color: initial 恢复默认
