CSS 关键字值演示

CSS 关键字是预定义的特殊值：inherit、initial、unset、revert、auto、none 等。
inherit：继承父元素 color 和 border color:inherit; border:inherit
initial：恢复为 CSS 规范初始值 color:initial; font-size:initial
unset：继承属性用 inherit，非继承属性用 initial color:unset; border:unset
revert：恢复为浏览器默认样式 color:revert
inherit 强制继承；initial 恢复规范默认；unset 智能重置；revert 恢复浏览器默认。
