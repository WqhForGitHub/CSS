第9章：颜色、背景和渐变

1. color 前景色

color: gray（命名颜色）

color: #600（十六进制）

color: rgb(100, 0, 0)（RGB）

color: hsl(0, 80%, 30%)（HSL）

color 影响边框颜色：

color: gray + border-style: solid → 边框也是灰色

color: gray + border-color: black → 边框颜色覆盖为黑色

2. background-color 背景色

background-color: silver

background-color: #aea

color: white + background-color: rgb(20%, 20%, 20%)（反色组合）

背景默认延伸到边框外边界，背景色不继承（默认 transparent）

3. background-clip 背景裁剪

background-clip: border-box（默认，延伸到边框外边界）
background-clip: padding-box（延伸到内边距外边界）
background-clip: content-box（仅内容区）

4. 线性渐变 linear-gradient

to top（白→黑）

to right（白→黑）

45deg（红→蓝）

多色渐变（彩虹）

5. 径向渐变 radial-gradient

circle（圆形渐变）

ellipse（椭圆渐变）

circle closest-side

circle at top left

6. 重复渐变

repeating-linear-gradient（条纹效果）

repeating-radial-gradient（同心圆效果）

7. currentColor 关键字

外层 color: blue，边框使用 currentColor 也是蓝色。
内层 color: red，边框使用 currentColor 变为红色

8. opacity 不透明度

opacity: 1.0（完全不透明）
opacity: 0.7
opacity: 0.4
opacity: 0.1（几乎透明）

注意：opacity 影响整个元素及其子元素，不同于 rgba 的半透明背景。
