条件样式加载示例

通过 <link> 标签的 media 属性，可以按条件加载不同的样式表文件。
<link rel="stylesheet" href="main.css" media="all"> <link rel="stylesheet" href="screen.css" media="screen and (min-width: 768px)"> <link rel="stylesheet" href="print.css" media="print">
screen.css — 仅在屏幕且宽度 ≥ 768px 时加载
print.css — 仅在打印时加载
条件加载可减少不必要的 CSS 下载，优化首屏性能。
