内外边距综合布局：卡片组件

使用 padding+margin 构建卡片组件：header/body/footer 三段式布局。

CSS 盒模型

padding 与 margin 综合应用

卡片头部使用 padding:16px 20px 营造舒适的内边距。body 区使用 padding:20px 与 header 保持视觉间距。

提示：footer 使用 border-top 分隔，padding:12px 20px 与 body 对齐。

段落间使用 margin-bottom:12px 创造垂直节奏感。最后一个段落 margin-bottom:0 避免多余空隙。
