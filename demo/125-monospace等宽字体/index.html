Monospace 等宽字体演示

等宽字体（Monospace）每个字符宽度相同，适合代码展示和表格对齐。
/* Courier New */ function hello() { console.log("Hello, World!"); return 42; }
/* Consolas */ function hello() { console.log("Hello, World!"); return 42; }
等宽字体表格对齐效果：
Name Age City Alice 30 NYC Bob 25 LA Charlie 35 SF
等宽字体每个字符等宽，适合代码、终端、表格对齐场景。
