content-box 标准盒模型

box-sizing: content-box（默认）：width/height 只包含内容区，padding 和 border 额外增加盒子尺寸。
width: 200px
实际宽度 = 200 + 20×2 + 5×2 = 250px
box-sizing: content-box (默认) 实际宽度 = width + padding-left + padding-right + border-left + border-right = 200 + 20 + 20 + 5 + 5 = 250px
content-box 下，增加 padding/border 会使元素变宽，可能破坏布局。
