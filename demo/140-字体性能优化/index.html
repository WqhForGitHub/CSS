字体加载性能优化

Web 字体影响首屏渲染。优化手段：font-display、preload、字体子集化、woff2 格式。
1. font-display: swap — 先显示回退字体，字体加载后替换
2. preload — <link rel="preload" href="font.woff2" as="font" crossorigin>
3. 字体子集化 — 仅包含页面使用的字符，大幅减小文件
4. woff2 格式 — 压缩率最高，现代浏览器全面支持
5. 限制字体数量 — 每种字重一个文件，最多 3-4 个文件
/* 最佳实践 */ @font-face { font-family: "App"; src: url("app-regular.woff2") format("woff2"); font-weight: 400; font-display: swap; unicode-range: U+0020-007E; /* 仅 ASCII */ }
中文字体文件通常 1-5MB，子集化可缩减到 50-200KB。
