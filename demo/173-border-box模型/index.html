border-box 盒模型

box-sizing: border-box：width/height 包含 padding 和 border，内容区自动缩小。推荐全局使用。
width: 200px
实际宽度 = 200px（padding 和 border 包含在内）
box-sizing: border-box 实际宽度 = width = 200px 内容区宽度 = 200 - 20×2 - 5×2 = 150px
/* 推荐全局重置 */ *, *::before, *::after { box-sizing: border-box; }
border-box 让布局更直观：设置多少宽度就是多少宽度。推荐全局使用。
