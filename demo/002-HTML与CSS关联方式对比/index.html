HTML 与 CSS 关联方式对比

CSS 与 HTML 关联有四种方式：link 外部引入、<style> 标签内嵌、@import 导入、行内 style 属性。它们在优先级、加载方式和维护性上各有差异。
方式 语法 优先级 可缓存 可复用
link 外部引入 <link rel="stylesheet" href="a.css"> 低 是 高
style 标签内嵌 <style>...</style> 低 否 中
@import 导入 @import url('a.css'); 低 是 中
行内 style <p style="color:red"> 高 否 低
推荐使用 link 外部引入：可被浏览器缓存、并行加载、便于维护。
