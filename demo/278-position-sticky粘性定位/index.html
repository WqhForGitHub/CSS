position sticky 粘性定位

position: sticky 在滚动到阈值前表现为 relative，到达阈值后变为 fixed。结合了 relative 和 fixed 的特性。
sticky 各段标题吸顶效果
第一章：CSS基础

滚动此区域，标题在到达顶部时会"粘住"。

在 sticky 阈值到达前，元素表现为 relative。

到达 top:0 后，变为类似 fixed 的行为。

第二章：选择器

每个标题在滚动到顶部时替换前一个固定标题。

这是文档目录常见效果。

sticky 元素只在父容器范围内有效。

第三章：盒模型

当父容器滚出视口时，sticky 元素也会跟着滚走。

这是 sticky 与 fixed 的重要区别。

第四章：定位

最后一章内容。

sticky 需要指定 top/bottom/left/right 中的至少一个值。

sticky 的关键限制：父容器不能有 overflow: hidden，且 sticky 元素只在父容器可见范围内生效。需要设置 top 等阈值才有效。
