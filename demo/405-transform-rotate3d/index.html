rotate3d 与 rotateZ

rotate3d(x,y,z,angle) 可以绕任意轴旋转，rotateZ() 则绕 Z 轴（垂直于屏幕）旋转，效果等同于 2D rotate()。

rotateZ 与 rotate3d 效果

Z30°
rotateZ(30deg)
Z45°
rotateZ(45deg)
3D-1
rotate3d(1,1,0,45deg)
3D-2
rotate3d(1,0,1,45deg)
3D-3
rotate3d(0,1,1,60deg)
3D-4
rotate3d(1,1,1,60deg)
rotate3d 的前三个参数定义旋转轴方向向量（不需要归一化），第四个参数为旋转角度。
