outline 轮廓与 border 区别

outline 是绘制在 border 外侧的轮廓，不占据布局空间，不影响盒模型尺寸。
border: 10px（占布局空间）
160+20=180px
盒子总宽 180px，被 border 撑大
outline: 10px（不占空间）
仍是 160px
盒子总宽 160px，outline 在外绘制
outline 与 border 的区别：
1. outline 不占布局空间，不影响盒模型尺寸
2. outline 可能不是矩形（在浏览器中可绕过元素）
3. outline 不能单独设置每条边（无 outline-top 等）
4. outline 不跟随 border-radius 圆角（旧规范，新版浏览器已支持）
outline 主要用于焦点指示器（:focus），不影响布局。可用 outline-offset 调整与边框的距离。
