中文字体适配方案

中文字体文件大，需特殊处理。常用方案：系统字体优先 + unicode-range 按需加载。
苹方/雅黑 — 现代无衬线中文字体。床前明月光，疑是地上霜。
宋体 — 传统衬线中文字体。床前明月光，疑是地上霜。
/* 中英文混合字体策略 */ body { font-family: -apple-system, "Helvetica Neue", "PingFang SC", "Microsoft YaHei", sans-serif; /* 英文优先系统字体，中文回退到苹方/雅黑 */ }
常用中文字体：
macOS: PingFang SC（苹方）、Songti SC（宋体）
Windows: Microsoft YaHei（微软雅黑）、SimSun（宋体）
Linux: WenQuanYi Micro Hei（文泉驿微米黑）
英文字体写在中文字体前，让英文使用专用英文字体，中文回退到中文字体。
