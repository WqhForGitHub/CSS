水平垂直居中方案对比

对比 flex、grid、position+transform、margin:auto、line-height 等多种居中方案的代码与适用场景。
方案1: flex（推荐，最常用）
flex 居中
.parent { display: flex; justify-content: center; align-items: center; }
方案2: grid + place-items（最简洁）
grid 居中
.parent { display: grid; place-items: center; }
方案3: position + transform（兼容性好）
绝对定位居中
.child { position: absolute; top: 50%; left: 50%; transform: translate(-50%,-50%); }
方案4: flex + margin:auto（子元素控制）
margin:auto
.parent { display: flex; } .child { margin: auto; }
方案5: line-height（仅单行文本）
line-height
.parent { line-height: 容器高度; text-align: center; }
现代项目推荐 flex 或 grid；老项目兼容性考虑用 position+transform；line-height 仅适用于单行文本。
