盒模型尺寸计算演示

用表格对比 content-box 与 border-box 在不同 padding/border 下的尺寸计算。
属性 content-box border-box
width 设置 200px（仅内容） 200px（含 padding+border）
padding +20px×2 = +40px 在 width 内
border +5px×2 = +10px 在 width 内
内容区宽度 200px 200-40-10 = 150px
盒子总宽度 250px 200px
布局影响 padding/border 撑大盒子 尺寸固定可控
content-box（总宽 250px）
250px
border-box（总宽 200px）
200px
计算公式：content-box 总宽 = width + padding×2 + border×2；border-box 总宽 = width（内容区自动收缩）。
