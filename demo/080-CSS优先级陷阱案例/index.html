CSS 优先级陷阱案例

展示常见的优先级陷阱：权重误判、继承干扰、!important 滥用等。
陷阱 1：权重误判
以为 .a.b.c (0,3,0) > #d (1,0,0)
实际：ID 权重永远高于任意数量的类
陷阱 2：继承不是权重
#parent { color: red; } 不会让 .child { color: blue; } 失效
继承值权重为 0，任何直接设置都覆盖继承
陷阱 3：!important 滥用
一旦使用 !important，后续覆盖也必须用 !important
最终代码充满 !important，难以维护
最佳实践：优先使用类选择器，控制层级深度，避免 !important。
