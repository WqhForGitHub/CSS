中文排版优化

中文排版需注意：首行缩进 2em、标点挤压、中英文间距、行高适当加大。

中文排版原则

中文段落首行缩进两个字符宽度（2em），这是中文书籍排版的标准规范。行高一般设置为字号的 1.5 到 1.8 倍，比英文略大，因为中文字形更密。

中文与英文、数字之间应保留适当间距。现代浏览器通常会自动处理这个间距，但也可以通过 CSS 精确控制。

中文排版使用两端对齐（justify）可以让段落看起来更整齐。配合 text-justify: inter-ideograph 可以获得更好的中文两端对齐效果。

中文排版推荐：2em 缩进、1.8 行高、justify 对齐、inter-ideograph。
