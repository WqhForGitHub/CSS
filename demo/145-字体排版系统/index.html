CSS 排版系统的设计原则

好的排版系统需要统一字号、字重、行高和字间距。使用 CSS 变量管理这些值，确保全站一致性。

1. 字号层级

标题从 h1 到 h3 逐级递减，正文使用 16px 基础字号。每级之间保持明显的视觉差异。

"排版是设计的骨架，内容是设计的血肉。"

2. 行高与字间距

正文行高推荐 1.5-1.8，标题行高 1.2-1.4。适当增加标题字间距提升品质感。

小结

通过 CSS 变量统一管理排版参数，可以在需要时快速调整全局样式。
