border-color 继承规则

border-color 默认值为 currentColor（继承元素的 color 属性）。
未指定 border-color — 默认使用 currentColor（即文字颜色）
color: #e74c3c，边框同色
显式指定 border-color
color: #e74c3c，border-color: #3498db
currentColor 关键字
color: #27ae60，border-color: currentColor
四边不同颜色
上红 右绿 下蓝 左橙
透明边框（保留布局占位）
border-color: transparent — 透明但仍占空间
currentColor 让边框颜色自动跟随文字颜色变化，常用于 hover 状态简化代码。
border-color 默认 currentColor，与 color 属性联动。利用此特性可减少 hover 状态的重复声明。
