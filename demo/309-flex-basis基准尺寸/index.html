flex-basis 基准尺寸

flex-basis 设置弹性项目在分配空间前的初始大小。优先级高于 width/height。
flex-basis 固定值
basis:100px
basis:200px
basis:auto
flex-basis 百分比
basis:30%
flex:1 1 100px
flex 简写对比
flex:1
(1 1 0%)
flex:2
(2 1 0%)
flex:auto
(1 1 auto)
flex:none
(0 0 auto)
flex 简写：flex: grow shrink basis。flex: 1 = 1 1 0%，flex: auto = 1 1 auto，flex: none = 0 0 auto。推荐使用简写而非单独设置。
