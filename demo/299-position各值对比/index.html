各定位值效果对比

relative

属性 脱离文档流 参考对象 原位置保留 top/left生效

absolute 是 最近非static祖先 否 是

sticky 在未到达阈值时表现为 relative（保留位置），到达阈值后表现为 fixed（固定位置）。*号表示条件性行为。fixed 在祖先有 transform/filter 时会改为相对该祖先定位。
