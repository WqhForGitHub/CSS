自定义 Web 字体加载

通过 @font-face 定义自定义字体，浏览器从指定 URL 下载字体文件。
@font-face { font-family: "MyFont"; src: url("myfont.woff2") format("woff2"), url("myfont.woff") format("woff"); font-weight: 400; font-display: swap; } .custom-text { font-family: "MyFont", sans-serif; }
字体格式优先级：woff2 > woff > ttf > eot
font-display: swap（先显示回退字体，加载后替换）
注意：字体文件需同源或配置 CORS
推荐使用 woff2 格式：压缩率最高，现代浏览器全面支持。
