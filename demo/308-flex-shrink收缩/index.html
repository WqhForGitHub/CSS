flex-shrink 收缩比例

flex-shrink 设置弹性项目的收缩比例，当空间不足时按比例缩小。默认为 1。
flex-shrink 不同比例（容器宽度400px）
shrink:1
min-width:150
shrink:2
min-width:150
shrink:0
min-width:150

空间不足时，shrink:2 的项目收缩量是 shrink:1 的两倍，shrink:0 不收缩

shrink:1 vs shrink:0
shrink:1
（会收缩）
shrink:0
（不收缩）
flex-shrink: 0 确保项目不会被压缩，保持原始宽度。这在固定侧边栏+自适应内容区的布局中很有用。flex-shrink 按比例分配收缩量，而非最终宽度比例。
