▶ HTML 结构

HTML（HyperText Markup Language）是构建网页的标准标记语言，描述了网页的结构和内容。

▶ CSS 样式

CSS（Cascading Style Sheets）用于控制网页的视觉表现，包括布局、颜色、字体、动画等各个方面。

▶ JavaScript 交互

JavaScript 是一种脚本语言，为网页添加动态交互功能，包括事件处理、DOM 操作、数据请求等。

max-height 过渡是 CSS 纯实现展开/收起的经典技巧。需要设置一个足够大的 max-height 值，但不宜过大以免影响动画速度。
