flex 简写属性详解

flex 是 flex-grow、flex-shrink、flex-basis 的简写。推荐使用简写而非单独设置。
flex 常用值对比
flex: 0 1 auto
initial（默认）
flex: 1 1 auto
auto
flex: 0 0 auto
none

initial(0 1 auto): 不扩展但可收缩
auto(1 1 auto): 可扩展可收缩
none(0 0 auto): 不扩展不收缩

flex: 1 vs flex: 2
flex:1
(1 1 0%)
flex:2
(2 1 0%)
flex:1

flex:1 和 flex:2 按 1:2 比例分配空间。basis 为 0% 表示不考虑原始尺寸。

推荐：使用 flex: 1、flex: auto、flex: none 等简写，而非单独写 flex-grow/shrink/basis。避免使用 flex-basis: 0 搭配 width。
