块格式化上下文 BFC 详解

BFC 是一个独立的渲染区域，内部元素按规则排列，不受外部影响。
BFC 特性：
1. 内部 Box 垂直排列
2. margin 不与外部折叠
3. 不与浮动重叠
4. 包含浮动子元素
5. 计算 height 时包含浮动子元素

触发 BFC 的条件

overflow: hidden/auto/scroll
float: left/right
position: absolute/fixed
display: flex/grid
display: inline-block
display: flow-root
display:flow-root 是专门为创建 BFC 设计的值，无副作用，推荐使用。
