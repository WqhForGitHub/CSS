transform-origin 变换原点

通过 transform-origin 属性可以改变元素的变换原点，默认值为 50% 50% 0（即元素中心）。

不同 transform-origin 下的旋转效果

鼠标悬停查看旋转效果，注意旋转中心点的差异：

中心
50% 50%（默认）
左上
0 0
右上
100% 0
左下
0 100%
右下
100% 100%
自定义
20px 30px
transform-origin 接受 1~3 个值：第一个为 X 轴，第二个为 Y 轴，第三个为 Z 轴。可以使用关键字（left/center/right/top/bottom）、百分比或长度值。
