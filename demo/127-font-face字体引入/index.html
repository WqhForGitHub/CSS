@font-face 字体引入实践

完整演示 @font-face 的各项属性：src、font-weight、font-style、unicode-range、font-display。
/* 定义多种字重 */ @font-face { font-family: "MyFont"; src: url("myfont-regular.woff2") format("woff2"); font-weight: 400; font-style: normal; font-display: swap; } @font-face { font-family: "MyFont"; src: url("myfont-bold.woff2") format("woff2"); font-weight: 700; font-display: swap; } /* 仅加载中文字符 */ @font-face { font-family: "CNFont"; src: url("cn.woff2") format("woff2"); unicode-range: U+4E00-9FFF; }
src — 字体文件路径和格式
font-weight/style — 对应的字重和样式
unicode-range — 仅加载指定 Unicode 范围的字符
font-display — 加载策略：auto/block/swap/fallback/optional
unicode-range 可按需加载中文字体，减少下载量。font-display: swap 是推荐默认值。
