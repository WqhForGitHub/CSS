position static 默认定位

position: static 是默认值，元素处于正常文档流中，top/right/bottom/left/z-index 属性无效。
static（默认值）
position: static
top:50px left:50px（无效）
static 元素2

top/left 属性对 static 元素无效，元素保持在正常文档流位置

对比 relative
position: relative
top:20px left:20px（生效）

relative 元素偏移后，原位置空间保留

所有元素默认 position: static。在 static 下，top、right、bottom、left 和 z-index 属性都不会生效。
