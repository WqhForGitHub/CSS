第3章：特指度和层叠

1. 特指度计算

这个段落的 color 由两个规则竞争：

p {color: gray;}           /* 0,0,0,1 */
body p {color: black;}    /* 0,0,0,2 胜出 */

结果：这段文字为黑色（body p 的特指度 0,0,0,2 大于 p 的 0,0,0,1）

2. 类选择符 vs 元素选择符

h2.grape-demo（0,0,1,1）- 紫色胜出

h2.silver-demo - 银色

类选择符（0,0,1,0）的特指度始终大于元素选择符（0,0,0,1），不管元素选择符有多少个。

3. ID 选择符 vs 属性选择符

id="meadow" - ID选择符(0,1,0,0) 绿色胜出
id="meadow-attr" - 属性选择符(0,0,1,0) 红色

注意：#meadow (0,1,0,0) 比 [id="meadow"] (0,0,1,0) 特指度高！

4. 行内样式最高

CSS 规则：h1#meadow-title { color: red; } (0,1,0,1)

行内 style="color: green" (1,0,0,0) 胜出

行内样式特指度为 1,0,0,0，比任何选择符都高。

5. !important 最高优先级

这段文字是灰色！虽然 .important-demo-override 设置了黑色，但 .important-demo 的 color 使用了 !important

!important 标记的声明始终胜出，无论特指度如何。

6. 继承没有特指度

Meerkat Central

#page-title 设了 color: black，但 * { color: gray } 的特指度（0,0,0,0）胜过继承（无特指度），所以 em 为灰色。

7. 层叠顺序（同等特指度时后者胜出）

两个规则特指度相同时，后出现的胜出：这段文字是蓝色而非红色

.cascade-demo { color: red; }
.cascade-demo { color: blue; }  /* 后出现，胜出 */
