适用场景对比
Flexbox 适合：导航栏、工具栏、媒体对象、表单输入组、单行/单列布局
Grid 适合：页面整体布局、卡片网格、仪表盘、画廊、二维复杂布局
最佳实践：Grid 做宏观布局，Flexbox 做微观组件
两者不是替代关系，而是互补。Grid 控制宏观二维结构，Flexbox 处理局部一维排列。嵌套使用可发挥各自优势。
