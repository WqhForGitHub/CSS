CSS 文档结构基础演示

CSS 核心目标是：为文档添加样式。文档结构由 HTML 定义，CSS 通过选择器匹配元素并应用声明。本演示展示文档树结构与样式的对应关系。

HTML 文档树结构

<html>
<head>
<meta> charset
<title>页面标题</title>
<link> rel="stylesheet"
<style> CSS规则 </style>
<body>
<h1>标题</h1>
<p>段落文本</p>
<div> 容器 </div>

CSS 作用的三个层级

html — 文档根元素
定义文档结构，是 CSS 作用的载体。
head — 头部信息区
放置 <style>、<link> 等 CSS 引入方式。
body — 可见内容区
CSS 选择器匹配 body 内的元素，应用视觉样式。
CSS 的本质：选择器 → 匹配文档树中的元素 → 应用声明（属性:值）
