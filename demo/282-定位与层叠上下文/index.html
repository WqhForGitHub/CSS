定位与层叠上下文

层叠上下文（Stacking Context）是CSS渲染中的概念。触发条件：position+z-index、opacity<1、transform、filter等。
不同方式触发的层叠上下文
normal
无层叠上下文
opacity:0.99
触发层叠上下文
transform
触发层叠上下文
filter
触发层叠上下文
触发层叠上下文的条件：
1. position 非 static + z-index 非 auto
2. opacity < 1
3. transform 不为 none
4. filter 不为 none
5. will-change 为指定值
6. display: flex/grid 子项 + z-index
一旦元素创建了新的层叠上下文，其子元素的 z-index 只在该上下文内比较，不会影响外部。理解这一点能解决很多"z-index 不生效"的问题。
