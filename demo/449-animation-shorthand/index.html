animation 简写属性

animation 简写属性可以在一行中设置所有动画参数：name, duration, timing-function, delay, iteration-count, direction, fill-mode, play-state。

animation 简写用法

脉冲
pulse 2s ease infinite alternate
旋转
spin 1.5s linear infinite
弹性
fadeScale 3s cubic-bezier 0.5s
移动
move 2s 3次 forwards
抖动
shake 0.5s infinite
简写格式：animation: name duration timing delay count direction fill-mode play-state。至少需要 name 和 duration。
