auto 居中布局实现

margin: auto 在块级和 flex 上下文中表现不同。块级仅水平居中，flex 可实现双向居中。
1. 块级 margin: 0 auto — 仅水平居中
水平居中
↑ 块级元素中 margin:auto 仅水平方向有效，垂直 auto 等于 0
2. 块级 margin: auto — 垂直方向仍无效
垂直方向 auto 无效
↑ 块级上下 margin:auto 不会让元素垂直居中
3. flex 容器中 margin: auto — 双向居中
flex 中双向居中
↑ flex 子元素 margin:auto 在剩余空间内双向分配，实现水平和垂直居中
.flex-parent { display: flex; } .flex-child { margin: auto; }
flex 子元素的 margin:auto 会吸收所有剩余空间，这是 flexbox 实现居中最简洁的方案之一。
