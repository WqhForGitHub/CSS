字体组合设计方案

好的字体组合提升设计质感。常见搭配：标题用衬线、正文用无衬线；或统一字体不同字重。
/* 衬线标题 + 无衬线正文 */

The Art of Typography

Good typography enhances readability and creates visual hierarchy. This combination pairs a serif heading with a sans-serif body for contrast.

/* 同字体不同字重 */

Clean and Modern

Using the same font family with different weights creates a clean, unified look. Bold for headings, light for body text.

/* 斜体衬线 + 等宽 */

Code Aesthetic

This combination works well for technical content. The italic serif heading adds elegance.

字体搭配原则：对比鲜明、风格统一、层次清晰。最多使用 2-3 种字体。
