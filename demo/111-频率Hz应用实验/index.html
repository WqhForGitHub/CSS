频率 Hz 应用实验

Hz（赫兹）是频率单位，主要用于 CSS 语音模块（speech）中的语速和音调控制。

Hz（赫兹）和 kHz 在 CSS 中用于语音属性：

voice-pitch: 120Hz; — 基础音调
voice-range: 240Hz; — 音调变化范围
voice-stress: moderate; — 语音强度
/* CSS Speech Module */ .speaker { voice-pitch: 120Hz; voice-range: 60Hz; speech-rate: 1.2; }
Hz 单位目前仅在 CSS Speech Module 中使用，浏览器支持有限。
