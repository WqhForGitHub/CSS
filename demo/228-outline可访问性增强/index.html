outline 可访问性增强

outline 是键盘用户导航的关键视觉指示器。不应 移除 outline，应增强它。
✗ 错误：移除 outline（键盘用户无法看到焦点）
链接
使用 Tab 键聚焦时看不到任何视觉指示，键盘用户无法知道当前焦点位置
✓ 基本：保留并增强 outline
链接
使用 outline + outline-offset 提供清晰的焦点指示
✓ 推荐：outline + box-shadow 双层指示
链接
outline 主指示 + box-shadow 光晕效果，视觉更明显，兼顾美观与可访问性
用 Tab 键试一下三个区域的按钮和链接，对比焦点效果差异。WCAG 2.1 标准：所有交互元素必须有可见的焦点指示。
绝不使用 outline:none 移除焦点。如需移除默认 outline，必须提供等效的替代焦点样式。
