position relative 相对定位

position: relative 相对于元素在正常文档流中的原始位置进行偏移，偏移后原位置空间保留。
relative 偏移效果
Box 1 正常
Box 2
top:20 left:30
Box 3 正常
Box 4
top:-15 right:-20
Box 5 正常
关键特点：
1. 原位置空间保留（其他元素不会填充空位）
2. 偏移参考为自身在文档流中的原始位置
3. 常用于为绝对定位子元素提供定位上下文
4. 负值向反方向偏移
position: relative 最常作为 position: absolute 子元素的定位参考。设置 relative 但不设偏移量时，视觉上无变化。
