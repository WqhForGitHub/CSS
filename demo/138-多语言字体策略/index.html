多语言字体策略

使用 unicode-range 为不同语言指定不同字体，实现精确的多语言字体控制。
@font-face { font-family: "MultiLang"; src: url("latin.woff2") format("woff2"); unicode-range: U+0000-007F; /* 基本拉丁文 */ } @font-face { font-family: "MultiLang"; src: url("cjk.woff2") format("woff2"); unicode-range: U+4E00-9FFF; /* CJK 统一汉字 */ } @font-face { font-family: "MultiLang"; src: url("emoji.woff2") format("woff2"); unicode-range: U+1F000-1F9FF; /* Emoji */ }
English: The quick brown fox.
日本語：こんにちは世界。
한국어: 안녕하세요 세계.

中文：你好世界。Emoji: 😀🎉

unicode-range 让浏览器仅下载页面中实际使用的字体文件。
