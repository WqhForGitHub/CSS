61. 检测 CSS 动画的 FPS

FPS = 每秒帧数，衡量动画流畅度。60 FPS 为理想，低于 30 会明显卡顿。
检测方法：① DevTools Performance/Frames 面板；② requestAnimationFrame 计算；③ PerformanceObserver。

动画演示

右上角实时显示当前 FPS（页面动画驱动）

方案1：requestAnimationFrame 手动统计

let lastTime = performance.now();
let frames = 0;
function tick(now) {
  frames++;
  if (now - lastTime >= 1000) {
    const fps = Math.round(frames * 1000 / (now - lastTime));
    console.log('FPS:', fps);
    frames = 0;
    lastTime = now;
  }
  requestAnimationFrame(tick);
}
requestAnimationFrame(tick);

方案2：PerformanceObserver（更精准）

const observer = new PerformanceObserver((list) => {
  list.getEntries().forEach(entry => {
    // entry.duration 即单帧耗时
    const fps = 1000 / entry.duration;
    console.log('单帧 FPS:', fps);
  });
});
observer.observe({ type: 'frame', buffered: true });

方案3：Chrome DevTools

  • F12 → Performance → Record → 录制后查看 Frames 时间轴
  • 每帧绿色块下显示时长，红色表示掉帧
  • Rendering 面板可勾选 "FPS meter" 实时显示

提升 FPS 的方法

  • 优先用 transform/opacity（合成层，不触发 reflow/repaint）
  • 避免动画 width/top/left/margin 等触发重排的属性
  • will-change 提前提升合成层
  • 对复杂动画降低帧率：每 2 帧渲染一次
  • 减少同时运行的动画数量
