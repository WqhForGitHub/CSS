27. CSS 优先级（Specificity）计算

优先级从高到低：
!important > 内联 style > ID选择器 > 类/伪类/属性选择器 > 元素/伪元素选择器 > 通配符。
采用 (A,B,C,D) 计数法：A=行内, B=ID个数, C=类/属性/伪类个数, D=元素/伪元素个数，逐位比较。
我是测试文字。内联pink + ID purple + 类green/red + !important orange。 最终颜色应是 orange（!important最高）。
选择器(A,B,C,D)说明
style=""1,0,0,0内联样式
#id0,1,0,0ID 选择器
.class / :hover / [attr]0,0,1,0类/伪类/属性
div / ::before0,0,0,1元素/伪元素
*0,0,0,0通配符（0优先级）

示例：#nav .item li:hover = 0,1,2,1（1个ID + 2个类/伪类 + 1个元素）

注意：11个类优先级 不等于 1个ID，是逐位比较不是十进制加法。
