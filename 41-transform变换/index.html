41. CSS3 transform 属性

transform 对元素进行 2D / 3D 变换，不脱离文档流（相对定位），不触发 reflow 仅合成层合成，性能好。
translate(20,10)
translateX(20)
scale(1.5)
scaleX(1.8)
rotate(45)
skew(20,10)
matrix()

↑ 2D 变换示例（蓝块原始位置在左上）

3D 变换（配合 perspective）

rotate3d(1,1,1,45)
rotateY(60)
rotateX(60)
属性作用
translate(x,y)平移
translateX/Y/Z单轴平移
scale(x,y)缩放
scaleX/Y/Z单轴缩放
rotate(deg)2D 旋转
rotateX/Y/Z / rotate3d3D 旋转
skew(x,y)倾斜
matrix / matrix3d矩阵（万能）
perspective透视（3D 景深）
