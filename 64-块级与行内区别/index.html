64. display: block / inline / inline-block 区别

三者是最基础的盒模型类型，决定元素的排版方式。

block（块级）

独占一行，可设宽高，默认宽度撑满父容器

block 150×60
↓ 我换行了
第二个 block

↑ block 元素自动换行，宽高生效

inline（行内）

不换行，宽高由内容决定，设置 width/height 无效，padding/margin 上下不影响布局

前文 inline 写了 width:150 height:60 但无效 后文紧挨

↑ inline 不换行，宽高被忽略，水平 padding/margin 生效但垂直不影响其他行

inline-block（行内块）

不换行（行内特性），但可设宽高（块特性）

前文 inline-block 150×60 生效第二个 后文

↑ inline-block 不换行且宽高生效，是前两者的结合

使用场景

  • block：区块容器、段落、卡片
  • inline：文本内的样式片段（a、strong、em）
  • inline-block：行内排列的按钮、图标块（注意空白间隙问题，见 demo 37/59）
  • 现代更推荐用 flex/grid 替代 inline-block 布局
